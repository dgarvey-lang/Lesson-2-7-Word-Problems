# Lesson 2.7: Quadratic Word Problems Review

An interactive review for solving quadratic word problems. For each problem, students:

1. Choose the equation that models the situation (wrong choices explain the mistake)
2. Pick the best method: factoring, taking square roots, the quadratic formula, or graphing
3. Solve, round to the nearest hundredth, and keep only the answers that make sense

Open `index.html` in a browser (or enable GitHub Pages for this repository).

- Starts with worksheet problems A–G: falling book, book onto a car, volleyball spike, garden against a fence, right triangle legs, two numbers, and lacrosse field
- Worked solutions with a written interpretation, plus a graph with the axes and key points labeled
- Feedback for negative times or widths, rounding errors, and switched values
- A built-in whiteboard for each question, and a calculator (with √, x², ^ and ANS) that can paste its result into the answer box
- A summary of results by problem type, with extra practice generated for weak areas

Progress is saved in the browser's local storage.
