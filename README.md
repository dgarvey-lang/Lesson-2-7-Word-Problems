# Lesson 2.7: Multiple Methods Review

An interactive review for solving quadratic equations by choosing the best method: factoring, taking square roots, the quadratic formula, or graphing.

Open `index.html` in a browser (or enable GitHub Pages for this repository).

- 15 starting problems from the Lesson 2.7 notes examples and practice problems A–H
- Step 1: pick the best method, with feedback on why
- Step 2: type the exact solutions (real or imaginary), with "almost" feedback for unsimplified or unreduced answers
- Worked solutions, step-by-step hints, and a graph check showing the x-intercepts
- A built-in whiteboard for each question
- A summary of results by question type, with extra practice generated for weak areas

Progress is saved in the browser's local storage.
